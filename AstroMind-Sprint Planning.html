⚙️ Sprint 1 — Core Backend Days 1–5 · LLM + Orchestration + Knowledge + Data
DAY 1 IBM Granite Connection + Prompt Engineering LLM Layer ⏱ 3h
  • 🔑Create .env file with IBM watsonx API key, project ID, and URL
  • 📝Write llm/client.py — WatsonxLLM wrapper that loads credentials from .env and returns a LangChain-compatible LLM object
  • 📝Write llm/prompts.py — full AstroMind system prompt with 5 sections including RAG context slot
  • 🧪Test: send a raw "Hello, I'm feeling stressed" message to Granite and print the raw response
✅ End of Day 1: IBM Granite responds to a test message via Python
DAY 2 LangChain Orchestration — Memory + Chain + Parser Orchestration Layer ⏱ 4h
  • 📝Write orchestration/memory.py — ConversationBufferMemory setup, session-scoped
  • 📝Write orchestration/output_parser.py — Pydantic model for {mood, score, risk_level, response, coping_strategy} + StructuredOutputParser
  • 📝Write orchestration/chain.py — wire memory + prompt + Granite LLM + parser into one LangChain chain
  • 🧪Test: send 3 back-to-back messages and confirm memory carries context between them
✅ End of Day 2: Multi-turn conversation works, Granite returns validated JSON every time
DAY 3 Docling PDF Ingestion + ChromaDB Vector Store Knowledge Layer ⏱ 4h
  • 📥Download NASA-STD-3001 Vol 2 and HRP Behavioral Health PDF → place in knowledge/docs/
  • 📝Write knowledge/ingestion.py — Docling parses each PDF → LangChain TextSplitter chunks into ~500 token segments
  • 📝Write knowledge/vectorstore.py — ChromaDB stores chunks, exposes similarity_search(query) function
  • 🧪Test: query "crew stress management" → confirm top 3 relevant NASA doc chunks are returned
✅ End of Day 3: NASA knowledge base is queryable — relevant passages surface on any psychological query
DAY 4 AI Core — Mood Engine + Risk Classifier + Coping Selector AI Core Layer ⏱ 4h
  • 📝Write core/mood_engine.py — extract mood label + wellness score (0–100) from parsed Granite output
  • 📝Write risk classifier inside mood_engine — dual detection: keyword scan + Granite risk_level field → final LOW/MEDIUM/HIGH
  • 📝Write core/coping.py — lookup table mapping each mood to 3 evidence-based coping strategies
  • 🧪Test: feed 5 sample messages covering all moods → verify correct score, risk, and coping strategy for each
✅ End of Day 4: Full mood pipeline works end-to-end — message in, {mood, score, risk, coping} out
DAY 5 SQLite Database + Session Summary Generator Data Layer ⏱ 3h
  • 📝Write data/database.py — create all 5 tables (sessions, mood_scores, messages, alerts, summaries) + insert/query functions
  • 📝Write core/summarizer.py — sends full session transcript to Granite via a separate summarization chain, stores result
  • 🧪Test: run a 5-message session → confirm all rows written correctly to DB → confirm summary generated and stored
✅ End of Day 5: Full backend pipeline complete — every session is stored, summarized, and retrievable
🏁
Sprint 1 Complete — Backend Milestone
IBM Granite ↔ LangChain ↔ NASA RAG ↔ Mood Engine ↔ SQLite — fully wired and tested
🖥️ Sprint 2 — UI, Dashboard & Demo Days 6–10 · Streamlit UI + Polish + Demo Prep
DAY 6 Streamlit Chat Interface UI Layer ⏱ 4h
  • 📝Write ui/chat.py — st.chat_message bubbles for astronaut and AstroMind, input box, session state management
  • 📝Write app.py — Streamlit entry point, wires chat UI to LangChain chain, handles session start/end
  • 🧪Test: run streamlit app, have a full 5-turn conversation, verify Granite responds in chat bubbles
✅ End of Day 6: Working chat UI — astronaut can type and AstroMind responds in real time
DAY 7 Mood Dashboard + Alert Panel UI Layer ⏱ 4h
  • 📝Write ui/dashboard.py — Plotly line chart of mood score over time, pulled from SQLite mood_scores table
  • 📝Write ui/alerts.py — st.error() banner for HIGH risk, st.warning() for MEDIUM, colour-coded risk badge per message
  • 🔗Integrate dashboard + alerts into app.py sidebar alongside chat
  • 🧪Test: simulate a HIGH risk message → confirm red alert banner appears instantly
✅ End of Day 7: Live mood chart + risk alerts visible alongside every conversation
DAY 8 Session Summary View + Full Integration Integration ⏱ 3h
  • 📝Add session summary panel to UI — st.expander shows AI-generated summary + final score + risk level at session end
  • 📝Add session history sidebar — list of past sessions with date, score, and risk badge pulled from SQLite
  • 🔗End-to-end integration test — full session: chat → mood tracking → alert → end session → summary → stored in DB
✅ End of Day 8: Complete user journey works from first message to session summary
DAY 9 Testing + Bug Fixes + UI Polish QA ⏱ 4h
  • 🧪Write tests/test_mood.py — unit tests for all 5 mood classifications and health score formula
  • 🧪Write tests/test_scenarios.py — 3 scripted conversation scenarios: calm crew member, stressed crew, HIGH risk detection
  • 🎨UI polish — page title, AstroMind logo/icon, sidebar layout, colour theme, welcome message
  • 🐛Fix any bugs found during testing — edge cases in JSON parsing, empty responses, DB errors
✅ End of Day 9: All tests pass, UI is clean and presentable, no known bugs
DAY 10 Demo Preparation + README + Final Run-Through Demo Day ⏱ 3h
  • 📄Write README.md — project overview, setup instructions, how to run, architecture summary
  • 🎬Prepare demo script — 3 scripted conversations showing CALM → STRESSED → HIGH RISK escalation arc
  • ✅Final end-to-end run-through — fresh venv, fresh DB, full demo script from scratch
  • 🚀Optional stretch: deploy to Streamlit Cloud for a shareable public URL
✅ End of Day 10: AstroMind MVP is demo-ready — live, tested, and documented
